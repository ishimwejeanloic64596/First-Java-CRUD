# First-Java-CRUD

A simple Java CRUD application built with Spring Boot, Vaadin and an in-memory H2 database.

## Run locally

    ./mvnw spring-boot:run

Then open http://localhost:8080.

Screenshots are in the `doc` folder.

## Technologies used

- Java
- Spring Boot
- Vaadin (web UI)
- H2 (in-memory database)
- Maven (via the included `mvnw` wrapper)
